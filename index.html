私人数字收藏架 · 把值得的，收进一个盒子
OPEN-SOURCE · NOTES · LOCAL FIRST

开源项目与灵感笔记，
收进你自己的收藏架。

SHELFBOX 把分类、置顶、搜索都装进一个纯静态页面。数据默认留在你的浏览器里，本地优先、离线可用；想跨设备同步时，连上自己的私有 Gist 即可——零构建，无需服务端。

现在开始收藏 看看它怎么工作
01 / FEATURES

功能特性

为个人收藏而设计

满足把东西长久收好、随时找回的一切需要——无需服务端，也不打断你的工作流。

纯静态

仓库本身就是页面，浏览器直接打开，数据留在自己的浏览器里，离线也能用。

模块化

每个功能独立成模块，存储与样式各自隔离，一个出问题也不影响其它模块。

零构建

零依赖、零构建，改完即上线，随处可托管，没有打包步骤也没有服务端。

02 / MODULES

功能模块

点开即进，互不打扰

分类目录、置顶卡片、标题直达阅读、实时体积提醒——让每一件收进来的东西都找得到。

03 / HOW IT WORKS

工作原理

本地优先，云端可选

无需配置，打开就能用。想在多台设备间保持一致时，连接一次自己的云端即可。

先写进本地

每次增删改都先落在浏览器自己的存储里，没有后端也能正常使用。

按需连接云端

填入一次 Token 并关联私有 Gist，内容才会开始在多台设备间流动。

逐条对账合并

以共同祖先为基准做三方合并，两端同时改动也能各留各的，不静默覆盖。

打开就是最新

其它设备打开页面时自动同步；没挂载的模块也能在后台接收云端改动。
